Basic Controls

All key bindings can be remapped in the game settings. The defaults listed here are the standard layout.

General​

ActionDefault Key
ChatEnter
Select / look at entityF
Open inventoryI
Open navigation panelN
Open faction menuH

Astronaut Mode — With Gravity​

ActionDefault Key
Move forwardW
Move backwardS
Strafe leftA
Strafe rightD
JumpSpace
Walk (slow)Left Shift
Look aroundMouse
Activate / interactR
Select item in hotbar1–9, 0 / Mouse wheel
Use / fire selected itemLeft Mouse Button
Secondary useRight Mouse Button

Astronaut Mode — Zero Gravity​

In zero-G all the same movement keys apply, plus:

ActionDefault Key
Move upSpace
Move downLeft Ctrl
Align to nearby structureSpace (tap while near)

Tip: Aligning to a structure also causes you to move with it if the structure is flying. This is useful for boarding moving ships.
