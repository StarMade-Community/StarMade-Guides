Basic Controls

All key bindings can be remapped in the game settings. The defaults listed here are the standard layout. Panel keys (inventory, map, catalog and so on) are listed in HUD & Interface.

General

Action Default Key
Chat Enter
Select the entity you are looking at F
Select next / previous entity ] / [
Radial menu Tab (hold)
Free the mouse cursor F2
Drop the selected item Backspace
Block shape menu T
Screenshot (with / without HUD) F5 / F6

On Foot

Action Default Key
Move W A S D
Sprint Double-tap W and hold
Jump Space
Crouch Left Shift (hold)
Prone Z
Look around Mouse
Activate / interact R
Select hotbar slot 1–9, 0 / Mouse wheel
Use / fire / place Left Mouse Button
Aim with a gun, or pick up a Ship Core Right Mouse Button
Melee Middle Mouse Button
Rotate block before placing Left Ctrl + Mouse wheel
Sit O
Emotes \ (hold)
Spawn a new ship (needs a Ship Core) X
Spawn a new station P

Zero Gravity

Action Default Key
Move up / down E / Q
Align to the structure in front of you Space
Magnetic boots: stand on the surface you are looking at / let go `

Tip: Aligning to a structure also makes you move with it if the structure is flying. This is useful for boarding moving ships.

See Character Movement for more on moving around.

Ship — Flight Mode

Action Default Key
Forward / backward W / S
Strafe left / right A / D
Strafe up / down Space / Left Ctrl
Roll left / right Q / E
Roll with the mouse Left Alt (hold) + Mouse
Brake Left Shift
Aim / look Mouse
Fire selected slot Left Mouse Button
Zoom Right Mouse Button
Select hotbar slot 1–9, 0 / Mouse wheel
Align camera to ship C
Free camera Right Shift (hold)
Reboot systems Y
Switch to build mode Z
Exit ship R
Turret AI on / off ,
Reset turret rotations .
Pin your selected target for the AI X

Ship — Build Mode

Action Default Key
Move W A S D, Space / Left Ctrl
Move faster Left Shift (hold)
Place block Left Mouse Button
Remove block Right Mouse Button
Rotate block Left Ctrl + Mouse wheel
Pick the block you are looking at Left Ctrl + Middle Mouse Button
Advanced build mode Left Ctrl (hold, or tap to toggle)
Build tools radial menu `
Select module (for linking) C
Link / unlink module to the selected one V
Jump to the selected module X
Undo / redo Ctrl+Z / Ctrl+Y
Flashlight P
Switch to flight mode Z
Exit ship R

See Advanced Building for the build tools.
